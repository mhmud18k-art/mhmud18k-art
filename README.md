## How I work

**Arabic is a first-class language, not a translation target.** Direction, numerals, typography and layout order are designed for it from the start — not mirrored afterwards.

**Accessibility is part of the build, not a pass at the end.** Focus rings stay, contrast ratios get measured, and reduced-motion preferences are honoured.

**The simplest thing that holds.** A framework earns its place or it doesn't ship — one of the projects above is deliberately plain ES modules because that is what the job needed.
